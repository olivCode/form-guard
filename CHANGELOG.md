# Changelog

## 1.0.0 — 2026-11-12

- First public stable PHP engine release, licensed under MIT.
- Session-bound tokens, randomized fields, honeypot, server timing and limits with progressive bans.
- Customizable profiles, rules and plugins with dependency/conflict validation.
- HTTP checks, optional Turnstile challenge, EN/FR translations and immutable form expiry.
- Private local storage, maintenance CLI and Composer or standalone PHP installation.
- Bilingual documentation, automated tests and application-focused runtime distributions.
